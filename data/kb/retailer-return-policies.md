# Hearing Aid Return Windows by Retailer (DEMO — verify before purchase)

- Costco Hearing Aid Centers: 180-day return window on hearing aids for a full refund.
- Jabra Enhance (direct): 100-day risk-free trial.
- Eargo (direct): 45-day return window.
- Lexie (direct): 45-day return window.
- Best Buy (Sony CRE series): 30-day return window for most customers; longer for paid members.
- Amazon: typically 30 days; some sellers offer 45 days. Check the listing.
- Caregiver tip: most people need 2–4 weeks to adjust to a hearing aid. Schedule a check-in at day 10 and a keep-or-return decision at least 5 days before the deadline.
